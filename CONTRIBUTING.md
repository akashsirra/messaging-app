# Contributing to DAMN Messaging

Thanks for your interest in contributing! 💬

DAMN Messaging is an open-source project, and contributions of all sizes are welcome.

## Ways to contribute

- 🐛 Report bugs
- 💡 Suggest features
- 🎨 Improve the UI/UX
- 📱 Improve mobile support
- 🧪 Add tests
- 🔐 Improve security
- 📚 Improve documentation
- 💻 Submit code

## Before opening a pull request

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes locally.
5. Keep commits focused and descriptive.
6. Open a pull request explaining what changed and why.

## Development

The project contains two main parts:

- `client/` — React + Vite frontend
- `server/` — Node.js + Express + Socket.io backend

Please avoid committing:

- `.env` files
- passwords
- API keys
- private keys
- local databases
- personal test data

## Pull requests

Please keep pull requests focused on one improvement whenever possible.

For larger features, open an issue first so the approach can be discussed before significant work begins.

## Code of conduct

Please be respectful and constructive when interacting with other contributors.

Thanks for helping make DAMN Messaging better! ❤️
